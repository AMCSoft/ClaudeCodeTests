## Capitolo 6 - Programmazione orientata agli oggetti

### Lezione 6.1 - Classi, costruttori e distruttori

Una classe incapsula dati e comportamento. `struct` e `class` differiscono solo per la visibilita' di default (pubblica vs privata). I costruttori inizializzano, il distruttore libera le risorse.

```cpp
#include <string>
#include <utility>

class Conto {
public:
    Conto(std::string titolare, double saldo = 0.0)
        : titolare_(std::move(titolare)), saldo_(saldo) {}
    void versa(double v) { saldo_ += v; }
    [[nodiscard]] double saldo() const noexcept { return saldo_; }
private:
    std::string titolare_;
    double saldo_;
};
```

- Usa la **lista di inizializzazione** dei membri.
- Marca `const` i metodi che non modificano lo stato.
- `explicit` sui costruttori a un argomento evita conversioni implicite.

### Lezione 6.2 - Regola del 5 / del 0, copia e move

Se una classe gestisce una risorsa servono: distruttore, costruttore di copia, assegnazione di copia, costruttore di move, assegnazione di move (**regola del 5**). Meglio ancora: usa membri che gestiscono la risorsa (`vector`, `unique_ptr`) e non scrivere nulla (**regola del 0**).

La **move semantics** (C++11) trasferisce le risorse da oggetti temporanei (rvalue) invece di copiarle: `std::move` converte in rvalue reference `T&&`.

```cpp
class Buffer {
    std::size_t n_; int* d_;
public:
    explicit Buffer(std::size_t n) : n_(n), d_(new int[n]{}) {}
    ~Buffer() { delete[] d_; }
    Buffer(const Buffer& o) : n_(o.n_), d_(new int[o.n_]) { std::copy(o.d_, o.d_ + n_, d_); }
    Buffer& operator=(Buffer o) noexcept { std::swap(n_, o.n_); std::swap(d_, o.d_); return *this; }
    Buffer(Buffer&& o) noexcept : n_(std::exchange(o.n_, 0)), d_(std::exchange(o.d_, nullptr)) {}
};
```

### Lezione 6.3 - Ereditarieta' e polimorfismo

Il polimorfismo a runtime usa funzioni `virtual`. La classe base deve avere distruttore virtuale. `override` e `final` rendono esplicite le intenzioni. Preferisci la composizione all'ereditarieta' quando possibile.

```cpp
#include <memory>
#include <vector>
#include <numbers>
struct Forma {
    virtual ~Forma() = default;
    virtual double area() const = 0;   // classe astratta
};
struct Cerchio : Forma {
    double r;
    explicit Cerchio(double r) : r(r) {}
    double area() const override { return std::numbers::pi * r * r; }
};
struct Rettangolo : Forma {
    double w, h;
    Rettangolo(double w, double h) : w(w), h(h) {}
    double area() const override { return w * h; }
};
int main() {
    std::vector<std::unique_ptr<Forma>> v;
    v.push_back(std::make_unique<Cerchio>(2));
    v.push_back(std::make_unique<Rettangolo>(3, 4));
    double tot = 0; for (auto& f : v) tot += f->area();
}
```

### Lezione 6.4 - Overloading degli operatori, eccezioni, principi SOLID

Si possono ridefinire operatori (`+`, `==`, `<<`, `[]`, `()`) per tipi definiti dall'utente: fallo solo quando il significato e' naturale. Le eccezioni (`try`/`catch`/`throw`) segnalano errori eccezionali; con RAII garantiscono la pulizia. In alternativa: `std::optional`, `std::expected` (C++23), codici di errore.

I principi **SOLID** (Single responsibility, Open/closed, Liskov, Interface segregation, Dependency inversion) guidano un design manutenibile. Pattern importanti: Strategy, Observer, Factory, Builder, Singleton (con cautela), Visitor, Decorator, Adapter.

#### Esempio svolto 6.1 - Una classe valore: Frazione

**Problema.** Progettare un tipo `Frazione` che si comporti come un numero: somma, prodotto, confronti e stampa, mantenendo sempre la forma ridotta con denominatore positivo.

**Ragionamento.** L'**invariante** della classe (ridotta, denominatore > 0) viene stabilito nel costruttore e preservato da ogni operazione, quindi il resto del codice puo' darlo per scontato. Gli operatori aritmetici si scrivono come funzioni libere `friend` (cosi' funzionano anche con un `int` a sinistra grazie al costruttore implicito); `operator<=>` di default non andrebbe bene, perche' confronterebbe i campi e non i valori, quindi lo definiamo con la moltiplicazione incrociata.

```cpp
#include <compare>
#include <iostream>
#include <numeric>
#include <stdexcept>

class Frazione {
    long long num_, den_;
public:
    Frazione(long long n = 0, long long d = 1) : num_(n), den_(d) {
        if (d == 0) throw std::invalid_argument("denominatore nullo");
        if (den_ < 0) { num_ = -num_; den_ = -den_; }
        long long g = std::gcd(num_, den_);
        num_ /= g; den_ /= g;
    }
    long long num() const { return num_; }
    long long den() const { return den_; }

    friend Frazione operator+(const Frazione& a, const Frazione& b) {
        return {a.num_ * b.den_ + b.num_ * a.den_, a.den_ * b.den_};
    }
    friend Frazione operator*(const Frazione& a, const Frazione& b) {
        return {a.num_ * b.num_, a.den_ * b.den_};
    }
    friend bool operator==(const Frazione&, const Frazione&) = default;  // forma ridotta
    friend std::strong_ordering operator<=>(const Frazione& a, const Frazione& b) {
        return a.num_ * b.den_ <=> b.num_ * a.den_;   // den > 0: il verso non cambia
    }
    friend std::ostream& operator<<(std::ostream& os, const Frazione& f) {
        return f.den_ == 1 ? os << f.num_ : os << f.num_ << '/' << f.den_;
    }
};

int main() {
    Frazione a{1, 2}, b{3, -4};
    std::cout << a << " + " << b << " = " << a + b << '\n';
    std::cout << a << " * " << b << " = " << a * b << '\n';
    std::cout << "2 + a = " << 2 + a << '\n';
    std::cout << std::boolalpha << (Frazione{2, 4} == a) << ' ' << (b < a) << '\n';
}
```

```text
1/2 + -3/4 = -1/4
1/2 * -3/4 = -3/8
2 + a = 5/2
true true
```

#### Esempio svolto 6.2 - Min Stack (LeetCode 155)

**Problema.** Progettare una pila che supporti `push`, `pop`, `top` e `getMin` tutte in O(1).

**Ragionamento.** Cercare il minimo a ogni chiamata costerebbe O(n). Trucco: accanto a ogni elemento memorizziamo il minimo della pila **fino a quel punto**. Quando togliamo un elemento, il minimo precedente e' gia' pronto nella coppia sottostante. L'interfaccia nasconde la rappresentazione: chi usa `MinStack` non sa (e non deve sapere) che dentro ci sono coppie.

```cpp
#include <algorithm>
#include <iostream>
#include <stdexcept>
#include <utility>
#include <vector>

class MinStack {
    std::vector<std::pair<int, int>> d_;   // (valore, minimo fino a qui)
public:
    void push(int x) { d_.emplace_back(x, d_.empty() ? x : std::min(x, d_.back().second)); }
    void pop() {
        if (d_.empty()) throw std::out_of_range("pila vuota");
        d_.pop_back();
    }
    int top() const { return d_.back().first; }
    int getMin() const { return d_.back().second; }
    bool empty() const { return d_.empty(); }
};

int main() {
    MinStack s;
    for (int x : {5, 3, 7, 2, 8}) s.push(x);
    while (!s.empty()) {
        std::cout << "top " << s.top() << " min " << s.getMin() << '\n';
        s.pop();
    }
}
```

```text
top 8 min 2
top 2 min 2
top 7 min 3
top 3 min 3
top 5 min 5
```

#### Esempio svolto 6.3 - Polimorfismo e pattern Strategy

**Problema.** Un carrello calcola il totale applicando uno sconto che puo' cambiare a runtime (nessuno, percentuale, "3x2"). Aggiungere nuovi sconti non deve richiedere modifiche al carrello (principio Open/Closed).

**Ragionamento.** Definiamo un'interfaccia astratta `Sconto` e la iniettiamo nel carrello tramite `std::unique_ptr` (dependency inversion: il carrello dipende dall'astrazione, non dalle classi concrete).

```cpp
#include <algorithm>
#include <iostream>
#include <memory>
#include <vector>

struct Sconto {
    virtual ~Sconto() = default;
    virtual double applica(const std::vector<double>& prezzi) const = 0;
};
struct NessunoSconto : Sconto {
    double applica(const std::vector<double>& p) const override {
        double t = 0; for (double x : p) t += x; return t;
    }
};
struct Percentuale : Sconto {
    double perc;
    explicit Percentuale(double p) : perc(p) {}
    double applica(const std::vector<double>& p) const override {
        return NessunoSconto{}.applica(p) * (1 - perc / 100);
    }
};
struct TrePerDue : Sconto {          // ogni 3 articoli il meno caro e' gratis (semplificato)
    double applica(const std::vector<double>& p) const override {
        double t = NessunoSconto{}.applica(p), minimo = p.empty() ? 0 : p[0];
        for (double x : p) minimo = std::min(minimo, x);
        return p.size() >= 3 ? t - minimo : t;
    }
};

class Carrello {
    std::vector<double> prezzi_;
    std::unique_ptr<Sconto> sconto_ = std::make_unique<NessunoSconto>();
public:
    void aggiungi(double p) { prezzi_.push_back(p); }
    void impostaSconto(std::unique_ptr<Sconto> s) { sconto_ = std::move(s); }
    double totale() const { return sconto_->applica(prezzi_); }
};

int main() {
    Carrello c;
    for (double p : {10.0, 20.0, 5.0}) c.aggiungi(p);
    std::cout << c.totale() << ' ';
    c.impostaSconto(std::make_unique<Percentuale>(10));
    std::cout << c.totale() << ' ';
    c.impostaSconto(std::make_unique<TrePerDue>());
    std::cout << c.totale() << '\n';
}
```

```text
35 31.5 30
```

## Capitolo 7 - Template e programmazione generica

### Lezione 7.1 - Template di funzione e di classe

I template generano codice per tipi diversi a compile time senza overhead a runtime.

```cpp
template <typename T>
T massimo(T a, T b) { return a < b ? b : a; }

template <typename T, std::size_t N>
class Array {
    T dati_[N]{};
public:
    constexpr T& operator[](std::size_t i) { return dati_[i]; }
    constexpr std::size_t size() const { return N; }
};

template <typename... Args>             // variadic template
auto somma(Args... args) { return (args + ...); }   // fold expression (C++17)
```

### Lezione 7.2 - Concepts, SFINAE e metaprogrammazione

I **concepts** (C++20) esprimono vincoli sui parametri template con messaggi d'errore chiari, sostituendo il vecchio SFINAE. `if constexpr` (C++17) sceglie il ramo a compile time. `<type_traits>` offre `is_integral_v`, `enable_if`, `remove_reference_t`, ecc.

```cpp
#include <concepts>
template <std::integral T>
T mcd(T a, T b) { return b == 0 ? a : mcd(b, a % b); }

template <typename T>
concept Stampabile = requires(T t, std::ostream& os) { os << t; };

template <Stampabile T>
void stampa(const T& x) { std::cout << x << '\n'; }

template <typename T>
auto descrivi(const T& v) {
    if constexpr (std::is_pointer_v<T>) return "puntatore";
    else return "valore";
}
```

#### Esempio svolto 7.1 - Un algoritmo generico vincolato da concepts

**Problema.** Scrivere una funzione che restituisce l'elemento massimo di **qualsiasi** range (vettore, array, lista, `string`...) purche' i suoi elementi siano confrontabili, con un errore di compilazione chiaro negli altri casi.

**Ragionamento.** Il concept `std::ranges::forward_range` vincola il contenitore; `std::totally_ordered` vincola il tipo degli elementi, ricavato con `std::ranges::range_value_t`. Restituiamo `std::optional` perche' un range vuoto non ha massimo.

```cpp
#include <concepts>
#include <iostream>
#include <list>
#include <optional>
#include <ranges>
#include <string>
#include <vector>

template <std::ranges::forward_range R>
    requires std::totally_ordered<std::ranges::range_value_t<R>>
std::optional<std::ranges::range_value_t<R>> massimo(const R& r) {
    auto it = std::ranges::begin(r);
    if (it == std::ranges::end(r)) return std::nullopt;
    auto m = *it;
    for (; it != std::ranges::end(r); ++it)
        if (m < *it) m = *it;
    return m;
}

struct Punto { int x, y; };   // nessun operator<: non soddisfa totally_ordered

int main() {
    std::vector<int> v{3, 9, 2};
    std::list<std::string> l{"pera", "mela", "uva"};
    std::cout << *massimo(v) << ' ' << *massimo(l) << ' ' << massimo(std::string("ciao")).value()
              << ' ' << massimo(std::vector<double>{}).has_value() << '\n';
    // massimo(std::vector<Punto>{});  // errore: vincoli non soddisfatti (totally_ordered)
}
```

```text
9 uva o 0
```

#### Esempio svolto 7.2 - Template variadici, fold expression e if constexpr

**Problema.** Scrivere `stampaTutto(args...)` che stampa un numero qualsiasi di argomenti separati da virgole, racchiudendo le stringhe tra virgolette e i booleani come `vero/falso`.

**Ragionamento.** Un **pack** di parametri si espande con una fold expression sull'operatore virgola. Per ogni elemento, `if constexpr` sceglie a compile time come formattarlo: i rami scartati non vengono nemmeno istanziati, quindi possono contenere codice che per quel tipo non compilerebbe.

```cpp
#include <iostream>
#include <string>
#include <string_view>
#include <type_traits>

template <typename T>
void stampaUno(const T& x) {
    using D = std::decay_t<T>;
    if constexpr (std::is_same_v<D, bool>) std::cout << (x ? "vero" : "falso");
    else if constexpr (std::is_convertible_v<D, std::string_view>) std::cout << '"' << x << '"';
    else if constexpr (std::is_floating_point_v<D>) std::cout << x << 'f';
    else std::cout << x;
}

template <typename... Args>
void stampaTutto(const Args&... args) {
    std::size_t i = 0;
    ((std::cout << (i++ ? ", " : ""), stampaUno(args)), ...);   // fold sulla virgola
    std::cout << " (" << sizeof...(args) << " argomenti)\n";
}

int main() {
    stampaTutto(42, "ciao", 3.5, true, std::string("C++"), 'x');
}
```

```text
42, "ciao", 3.5f, vero, "C++", x (6 argomenti)
```

#### Esempio svolto 8.1 - Configurazione con optional, variant e visit

**Problema.** Leggere righe `chiave = valore` e memorizzare il valore con il tipo giusto (intero, reale, booleano o stringa); poi stampare ogni voce con il suo tipo. Le righe senza `=` vanno ignorate.

**Ragionamento.** `std::variant` e' un'unione type-safe: contiene esattamente uno dei tipi elencati. Per visitarlo usiamo il classico idioma `overloaded`, che eredita da piu' lambda e ne unisce gli `operator()`. `std::optional` esprime il "forse": una riga non valida restituisce `std::nullopt` invece di un codice di errore.

```cpp
#include <charconv>
#include <iostream>
#include <map>
#include <optional>
#include <string>
#include <variant>

using Valore = std::variant<long, double, bool, std::string>;

template <typename... F> struct overloaded : F... { using F::operator()...; };

std::string ripulisci(std::string s) {
    auto a = s.find_first_not_of(' '), b = s.find_last_not_of(' ');
    return a == std::string::npos ? "" : s.substr(a, b - a + 1);
}

Valore interpreta(const std::string& s) {
    if (s == "true" || s == "false") return s == "true";
    long l; auto fine = s.data() + s.size();
    if (auto [p, e] = std::from_chars(s.data(), fine, l); e == std::errc{} && p == fine) return l;
    double d;
    if (auto [p, e] = std::from_chars(s.data(), fine, d); e == std::errc{} && p == fine) return d;
    return s;
}

std::optional<std::pair<std::string, Valore>> leggiRiga(const std::string& riga) {
    auto pos = riga.find('=');
    if (pos == std::string::npos) return std::nullopt;
    return std::pair{ripulisci(riga.substr(0, pos)), interpreta(ripulisci(riga.substr(pos + 1)))};
}

int main() {
    std::map<std::string, Valore> conf;
    for (std::string r : {"porta = 8080", "ratio=0.75", "debug = true", "commento", "nome = srv"})
        if (auto kv = leggiRiga(r)) conf.insert(*kv);

    for (const auto& [k, v] : conf)
        std::visit(overloaded{
            [&](long x) { std::cout << k << ": intero " << x << '\n'; },
            [&](double x) { std::cout << k << ": reale " << x << '\n'; },
            [&](bool x) { std::cout << k << ": bool " << std::boolalpha << x << '\n'; },
            [&](const std::string& x) { std::cout << k << ": stringa " << x << '\n'; },
        }, v);
}
```

```text
debug: bool true
nome: stringa srv
porta: intero 8080
ratio: reale 0.75
```

#### Esempio svolto 8.2 - Elaborare dati con ranges e proiezioni

**Problema.** Data una lista di studenti con nome, corso e voto, stampare in ordine di voto decrescente i nomi dei promossi (voto >= 18) del corso "C++", e calcolarne la media.

**Ragionamento.** Gli algoritmi `std::ranges::` accettano una **proiezione**: `std::ranges::sort(v, std::greater{}, &Studente::voto)` ordina per voto senza scrivere un comparatore. Le viste (`views::filter`, `views::transform`) sono pigre: non creano copie, calcolano gli elementi solo quando li si scorre.

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <numeric>
#include <ranges>
#include <string>
#include <vector>

struct Studente { std::string nome, corso; int voto; };

int main() {
    std::vector<Studente> v{{"Anna", "C++", 28}, {"Bruno", "Java", 30}, {"Carla", "C++", 17},
                            {"Dario", "C++", 24}, {"Elena", "C++", 30}};
    std::ranges::sort(v, std::greater{}, &Studente::voto);

    auto promossi = v | std::views::filter([](const Studente& s) {
                            return s.corso == "C++" && s.voto >= 18; });
    for (const auto& nome : promossi | std::views::transform(&Studente::nome))
        std::cout << nome << ' ';

    auto voti = promossi | std::views::transform(&Studente::voto);
    double somma = std::accumulate(voti.begin(), voti.end(), 0.0);
    std::cout << "| media " << somma / std::ranges::distance(promossi) << '\n';
}
```
