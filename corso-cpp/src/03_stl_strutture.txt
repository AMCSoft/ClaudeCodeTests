### Lezione 9.1 - Contenitori sequenziali

La STL si compone di **contenitori**, **iteratori** e **algoritmi**. Contenitori sequenziali: `std::array` (dimensione fissa), `std::vector` (array dinamico, il default), `std::deque`, `std::list` (lista doppia), `std::forward_list`.

| Contenitore | Accesso | Inserimento in coda | Inserimento in mezzo |
|---|---|---|---|
| vector | O(1) | O(1) ammortizzato | O(n) |
| deque | O(1) | O(1) | O(n) |
| list | O(n) | O(1) | O(1) con iteratore |

Nota pratica: `std::vector` e' quasi sempre piu' veloce di `std::list` grazie alla localita' di cache. Usa `reserve()` se conosci la dimensione e `emplace_back` per costruire in loco.

```cpp
std::vector<int> v;
v.reserve(100);
for (int i = 0; i < 100; ++i) v.emplace_back(i);
v.erase(std::remove_if(v.begin(), v.end(), [](int x){ return x % 2; }), v.end()); // erase-remove
std::erase_if(v, [](int x){ return x > 50; });   // C++20
```

#### Esempio svolto 9.1 - Merge Intervals (LeetCode 56)

**Problema.** Dato un elenco di intervalli `[inizio, fine]`, fondere quelli sovrapposti. Esempio: `[1,3] [2,6] [8,10] [15,18]` diventa `[1,6] [8,10] [15,18]`.

**Ragionamento.** Dopo aver ordinato per inizio, due intervalli che si sovrappongono sono per forza **consecutivi**. Scorriamo una volta: se l'intervallo corrente inizia prima della fine dell'ultimo fuso, estendiamo quest'ultimo; altrimenti ne apriamo uno nuovo. Costo: O(n log n) per l'ordinamento, O(n) per la scansione. Un `std::pair` si ordina gia' lessicograficamente, quindi basta `std::sort` senza comparatore.

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>

using Intervallo = std::pair<int, int>;

std::vector<Intervallo> fondi(std::vector<Intervallo> v) {   // per valore: lo ordiniamo
    std::sort(v.begin(), v.end());
    std::vector<Intervallo> out;
    for (const auto& [a, b] : v) {
        if (!out.empty() && a <= out.back().second)
            out.back().second = std::max(out.back().second, b);
        else
            out.emplace_back(a, b);
    }
    return out;
}

int main() {
    for (auto [a, b] : fondi({{8, 10}, {1, 3}, {15, 18}, {2, 6}, {17, 20}}))
        std::cout << '[' << a << ',' << b << "] ";
    std::cout << '\n';
}
```

```text
[1,6] [8,10] [15,20]
```

#### Esempio svolto 9.2 - Top K Frequent Elements (LeetCode 347)

**Problema.** Restituire i `k` elementi piu' frequenti di un vettore.

**Ragionamento.** Primo passo: contare le occorrenze con `std::unordered_map` (O(n)). Secondo passo: scegliere i k migliori. Ordinare tutte le coppie costerebbe O(m log m) con m valori distinti; `std::partial_sort` ordina solo i primi k, in O(m log k). A parita' di frequenza ordiniamo per valore, cosi' l'output e' deterministico (l'ordine di iterazione di una `unordered_map` non lo e').

```cpp
#include <algorithm>
#include <iostream>
#include <unordered_map>
#include <utility>
#include <vector>

std::vector<int> topK(const std::vector<int>& a, std::size_t k) {
    std::unordered_map<int, int> freq;
    for (int x : a) ++freq[x];
    std::vector<std::pair<int, int>> v(freq.begin(), freq.end());   // (valore, frequenza)
    k = std::min(k, v.size());
    std::partial_sort(v.begin(), v.begin() + k, v.end(), [](const auto& x, const auto& y) {
        return x.second != y.second ? x.second > y.second : x.first < y.first;
    });
    std::vector<int> out;
    for (std::size_t i = 0; i < k; ++i) out.push_back(v[i].first);
    return out;
}

int main() {
    for (int x : topK({4, 1, 1, 1, 2, 2, 3, 4, 4, 5, 2, 2}, 3)) std::cout << x << ' ';
    std::cout << '\n';
}
```

```text
2 1 4
```

Alternativa da conoscere: **bucket sort** per frequenza (vettore di liste indicizzato dalla frequenza) che porta il costo a O(n).

#### Esempio svolto 9.3 - Scegliere il contenitore giusto

**Problema.** Un sistema riceve eventi `(timestamp, utente)` e deve rispondere a: (a) "quanti utenti distinti?", (b) "quali eventi tra t1 e t2?", (c) "qual e' l'ultimo evento?". Quali contenitori usare?

**Ragionamento.** (a) appartenenza senza ordine: `std::unordered_set` (O(1) medio). (b) ricerca per intervallo su chiavi ordinate: `std::multimap` (piu' eventi possono avere lo stesso timestamp) con `lower_bound`/`upper_bound` in O(log n). (c) l'ultimo elemento di una mappa ordinata e' `rbegin()`.

```cpp
#include <iostream>
#include <map>
#include <string>
#include <unordered_set>

int main() {
    std::multimap<int, std::string> eventi{{10, "anna"}, {12, "bruno"}, {12, "anna"},
                                           {15, "carla"}, {20, "dario"}};
    std::unordered_set<std::string> utenti;
    for (const auto& [t, u] : eventi) utenti.insert(u);
    std::cout << "distinti: " << utenti.size() << '\n';

    for (auto it = eventi.lower_bound(11); it != eventi.upper_bound(15); ++it)
        std::cout << it->first << ':' << it->second << ' ';
    std::cout << "\nultimo: " << eventi.rbegin()->second << '\n';
}
```

```text
distinti: 4

ultimo: dario
```

### Lezione 10.1 - Liste concatenate, pile e code

Implementare le strutture a mano insegna la gestione della memoria. Esempio: pila con lista singola e unique_ptr.

```cpp
template <typename T>
class Pila {
    struct Nodo { T val; std::unique_ptr<Nodo> next; };
    std::unique_ptr<Nodo> testa_;
    std::size_t n_ = 0;
public:
    void push(T v) { testa_ = std::unique_ptr<Nodo>(new Nodo{std::move(v), std::move(testa_)}); ++n_; }
    T pop() { T v = std::move(testa_->val); testa_ = std::move(testa_->next); --n_; return v; }
    const T& top() const { return testa_->val; }
    bool empty() const { return n_ == 0; }
};
```

Temi: lista doppia, lista circolare, coda circolare (ring buffer), deque. Tecniche: due puntatori (lento/veloce), nodo sentinella, inversione in loco.

### Lezione 10.2 - Alberi binari e di ricerca

Un albero binario ha nodi con al massimo due figli. Un BST mantiene `sinistro < nodo < destro`. Visite: pre-order, in-order, post-order, per livelli (BFS). Alberi bilanciati: AVL, rosso-nero (usato da `std::map`), B-tree (database e file system).

```cpp
struct Nodo { int val; Nodo *sx = nullptr, *dx = nullptr; };

void inorder(const Nodo* n, std::vector<int>& out) {
    if (!n) return;
    inorder(n->sx, out); out.push_back(n->val); inorder(n->dx, out);
}
int altezza(const Nodo* n) { return n ? 1 + std::max(altezza(n->sx), altezza(n->dx)) : 0; }
```

### Lezione 10.3 - Heap, tabelle hash, trie, union-find

- **Heap** (coda con priorita'): inserimento/estrazione O(log n); `std::priority_queue`, `make_heap`.
- **Tabella hash**: funzione di hash + gestione collisioni (concatenamento o indirizzamento aperto); fattore di carico e rehash.
- **Trie**: albero di prefissi per dizionari e autocompletamento.
- **Union-Find (DSU)**: insiemi disgiunti con path compression e union by rank, quasi O(1).
- **Segment tree / Fenwick tree**: query su intervalli in O(log n).
- **Skip list, Bloom filter, LRU cache**: strutture usate nei database e nei sistemi distribuiti.

```cpp
struct DSU {
    std::vector<int> p, r;
    explicit DSU(int n) : p(n), r(n, 0) { std::iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unisci(int a, int b) {
        a = find(a); b = find(b); if (a == b) return false;
        if (r[a] < r[b]) std::swap(a, b);
        p[b] = a; if (r[a] == r[b]) ++r[a]; return true;
    }
};
```

### Lezione 10.4 - Grafi

Rappresentazioni: matrice di adiacenza, liste di adiacenza (`vector<vector<int>>`), lista di archi. Visite: BFS (cammini minimi non pesati, livelli) e DFS (componenti connesse, cicli, ordinamento topologico).

```cpp
std::vector<int> bfs(const std::vector<std::vector<int>>& g, int s) {
    std::vector<int> dist(g.size(), -1);
    std::queue<int> q; q.push(s); dist[s] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) if (dist[v] < 0) { dist[v] = dist[u] + 1; q.push(v); }
    }
    return dist;
}
```

#### Esempio svolto 10.1 - Parentesi bilanciate con una pila (LeetCode 20)

**Problema.** Verificare che in una stringa con `()[]{}` ogni parentesi aperta sia chiusa dal tipo giusto e nell'ordine giusto.

**Ragionamento.** L'ultima parentesi aperta deve essere la prima a chiudersi: e' il comportamento LIFO di una pila. Per ogni apertura facciamo `push` della chiusura attesa; per ogni chiusura controlliamo che coincida con la cima. Alla fine la pila deve essere vuota.

```cpp
#include <iostream>
#include <stack>
#include <string_view>

bool bilanciata(std::string_view s) {
    std::stack<char> attese;
    for (char c : s) {
        switch (c) {
            case '(': attese.push(')'); break;
            case '[': attese.push(']'); break;
            case '{': attese.push('}'); break;
            case ')': case ']': case '}':
                if (attese.empty() || attese.top() != c) return false;
                attese.pop();
                break;
            default: break;                 // altri caratteri ignorati
        }
    }
    return attese.empty();
}

int main() {
    for (auto s : {"{[()]}", "([)]", "((", "f(a[i]) { return; }"})
        std::cout << s << " -> " << (bilanciata(s) ? "ok" : "errore") << '\n';
}
```

```text

([)] -> errore
(( -> errore
f(a[i]) { return; } -> ok
```

#### Esempio svolto 10.2 - Un albero binario di ricerca completo

**Problema.** Implementare un BST di interi con inserimento, ricerca, visita in ordine, visita per livelli e altezza, senza memory leak.

**Ragionamento.** Ogni nodo possiede i figli con `std::unique_ptr`. L'inserimento ricorsivo prende un **riferimento** al puntatore da riempire, cosi' non serve distinguere il caso "albero vuoto". La visita in ordine di un BST produce le chiavi ordinate; quella per livelli usa una coda (BFS). In un albero bilanciato le operazioni costano O(log n), ma con inserimenti gia' ordinati degenera in una lista: O(n).

```cpp
#include <iostream>
#include <memory>
#include <queue>
#include <vector>

class BST {
    struct Nodo {
        int k;
        std::unique_ptr<Nodo> sx, dx;
    };
    std::unique_ptr<Nodo> radice_;

    static void inserisci(std::unique_ptr<Nodo>& n, int k) {
        if (!n) n = std::make_unique<Nodo>(Nodo{k, nullptr, nullptr});
        else if (k < n->k) inserisci(n->sx, k);
        else if (k > n->k) inserisci(n->dx, k);        // duplicati ignorati
    }
    static void inordine(const Nodo* n, std::vector<int>& out) {
        if (!n) return;
        inordine(n->sx.get(), out); out.push_back(n->k); inordine(n->dx.get(), out);
    }
    static int altezza(const Nodo* n) {
        return n ? 1 + std::max(altezza(n->sx.get()), altezza(n->dx.get())) : 0;
    }
public:
    void inserisci(int k) { inserisci(radice_, k); }
    bool contiene(int k) const {
        for (const Nodo* n = radice_.get(); n; n = k < n->k ? n->sx.get() : n->dx.get())
            if (n->k == k) return true;
        return false;
    }
    std::vector<int> ordinati() const { std::vector<int> v; inordine(radice_.get(), v); return v; }
    int altezza() const { return altezza(radice_.get()); }
    void stampaLivelli() const {
        std::queue<const Nodo*> q;
        if (radice_) q.push(radice_.get());
        while (!q.empty()) {
            for (auto n = q.size(); n > 0; --n) {      // un livello alla volta
                const Nodo* x = q.front(); q.pop();
                std::cout << x->k << ' ';
                if (x->sx) q.push(x->sx.get());
                if (x->dx) q.push(x->dx.get());
            }
            std::cout << '\n';
        }
    }
};

int main() {
    BST t;
    for (int k : {50, 30, 70, 20, 40, 60, 80, 35}) t.inserisci(k);
    for (int k : t.ordinati()) std::cout << k << ' ';
    std::cout << "\naltezza " << t.altezza() << ", contiene 35? " << t.contiene(35)
              << ", contiene 36? " << t.contiene(36) << '\n';
    t.stampaLivelli();
}
```

```text
20 30 35 40 50 60 70 80
altezza 4, contiene 35? 1, contiene 36? 0
50
30 70
20 40 60 80
35
```

#### Esempio svolto 10.3 - Ordinamento topologico: Course Schedule (LeetCode 207/210)

**Problema.** Ci sono `n` corsi e coppie `(a, b)` che significano "per seguire a devi aver seguito b". Trovare un ordine valido in cui seguirli, o stabilire che non esiste (dipendenze circolari).

**Ragionamento.** E' un grafo orientato: arco `b -> a`. L'algoritmo di **Kahn** parte dai corsi senza prerequisiti (grado entrante 0), li "segue" e decrementa il grado entrante dei successori; chi arriva a 0 entra in coda. Se alla fine non abbiamo seguito tutti i corsi, c'e' un ciclo. Costo O(V + E).

```cpp
#include <iostream>
#include <queue>
#include <utility>
#include <vector>

std::vector<int> ordineCorsi(int n, const std::vector<std::pair<int, int>>& prereq) {
    std::vector<std::vector<int>> g(n);
    std::vector<int> gradoIn(n, 0);
    for (auto [a, b] : prereq) { g[b].push_back(a); ++gradoIn[a]; }

    std::queue<int> q;
    for (int i = 0; i < n; ++i) if (gradoIn[i] == 0) q.push(i);
    std::vector<int> ordine;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ordine.push_back(u);
        for (int v : g[u]) if (--gradoIn[v] == 0) q.push(v);
    }
    if ((int)ordine.size() != n) return {};                 // ciclo
    return ordine;
}

int main() {
    auto o = ordineCorsi(6, {{1, 0}, {2, 0}, {3, 1}, {3, 2}, {4, 3}, {5, 4}});
    for (int c : o) std::cout << c << ' ';
    std::cout << "\nciclo? " << ordineCorsi(3, {{0, 1}, {1, 2}, {2, 0}}).empty() << '\n';
}
```

```text
0 1 2 3 4 5
ciclo? 1
```
